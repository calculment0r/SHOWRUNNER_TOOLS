SR—07 · Movie Analysis

Le film plan par plan

Le code mesure, le modèle juge, le code vérifie. Les coupes, les durées et le mouvement sont mesurés ; la transcription, les personnages suivis puis nommés et qui parle sont calculés ; l'échelle, la catégorie, la caméra et le rythme de chaque plan sont jugés par le modèle, puis vérifiés par quinze portes. Tout tourne sur les DGX.
